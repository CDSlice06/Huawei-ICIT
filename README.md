# 知识系统化应用（Knowledge System）

> 第十一届华为ICT大赛创新赛 · 赛道一（赛题1：基于华为云产品打造AI创新应用）参赛作品

## 项目简介

知识系统化应用是一款面向**教育行业与个人成长**场景的 AI 知识管理工具，解决"学过的知识随时间流逝而遗忘"的真实痛点：

**多源知识一键转化 → 结构化沉淀 → 思维导图呈现 → 抗遗忘复习** 完整闭环。

每个用户均为独立个体，知识数据严格隔离；错题拍照一键沉淀为结构化错题本，并可按策略抽取组织测验，强化薄弱知识点。

## 核心功能

| 优先级 | 功能 | 说明 |
|--------|------|------|
| **P0** | 多源知识导入 | 粘贴文本 / 上传文档（PDF、Word、Markdown、TXT）/ 拍照图片，一键转化 |
| **P0** | AI 结构化卡片 | 大模型生成"标题-摘要-要点-问答-标签"知识卡片，可溯源、可编辑 |
| **P0** | 思维导图 | 基于知识卡片自动生成层级导图，节点可跳转对应卡片 |
| **P0** | 抗遗忘复习 | 基于遗忘曲线排定复习任务，掌握度自评驱动间隔动态调整 |
| **P1** | 错题本与测验 | 错题图片/描述一键转结构化条目，按顺序/随机抽取组题测验 |
| **P1** | 知识搜索 | 跨卡片/素材/错题的全局与库内搜索，相关性排序 |
| **P2** | 知识分享论坛 | 知识库发布快照分享，全站只读浏览 |
| **P2** | 导图拼图自测 | 导图节点打散拼装，自测知识大纲掌握程度 |

## 技术栈

- **AI 能力**：华为云 MaaS 大模型（结构化转换、多模态图片识别）
- **数据持久化**：华为云 RDS（MySQL）+ Redis 缓存
- **对象存储**：华为云 OBS
- **部署**：华为云 ECS，云上在线演示

> 完整技术选型与架构设计随开发迭代持续更新。
